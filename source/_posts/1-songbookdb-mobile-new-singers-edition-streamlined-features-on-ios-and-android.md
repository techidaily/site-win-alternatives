## 1. SongbookDB Mobile: New Singers Edition - Streamlined Features on iOS & Android

[![online song book songbookdb update 1.5.6](https://i0.wp.com/pcdj.com/wp-content/uploads/2016/07/songbookdbappupdate-coverimage.jpg?resize=706%2C321&ssl=1)](https://i0.wp.com/pcdj.com/wp-content/uploads/2016/07/songbookdbappupdate-coverimage.jpg?fit=706%2C360&ssl=1 "online song book songbookdb update 1.5.6")

The **[SongbookDB](https://tools.techidaily.com/pcdj/products/)** singer app, used to browse, search and request songs, has been updated to version 1.5.6\. The **free maintenance update** is available for both Android and iOS.

#### Here’s what’s new and improved:

* Set up auto-pagination, so when singers get to the bottom of search results the next 50 results are auto-loaded
* Fixed some UI features that appeared out of place or off-center on larger mobile screens
* Updated Facebook graph to 2.6

Singer **song requests come in via the internet** directly to the SongbookDB plug-in for Karaoki. Simply click ‘accept’ to send the singers name and song request to Karaoki’s rotation list.
